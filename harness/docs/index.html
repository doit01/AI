🚀 Harness 项目

全栈 Spring Boot 4 + Vue 3 演示项目 — JPA 关联关系实战 + 多智能体编排 (OMO)

📋 项目概览

Harness 是一个用于演示 Spring Data JPA 核心关联关系的全栈项目，覆盖 OneToMany 自引用、ManyToOne、ManyToMany 三种主流场景。 同时集成了 Oh My OpenAgent (OMO) 多智能体编排，提供 10+ 专业 AI 智能体辅助开发。

🔗 JPA 关联关系总览

关系实体说明
@OneToMany 自引用Department → Department部门树（parent/children）
@ManyToOneUser → Department用户所属部门
@ManyToManyUser ↔ Role用户-角色（sys_user_role）
@ManyToManyRole ↔ Menu角色-菜单（sys_role_menu）
@OneToMany 自引用Menu → Menu菜单树（parent/children）
@ManyToManyStudent ↔ Course学生选课（mm_student_course）

🛠️ 后端技术要点

🏗️ 按领域分包

不再按 entity/ service/ controller/ 分层，而是每个领域一个包，包含完整 CRUD 闭环：

com.demo/department/
├── Department.java         (Entity)
├── DepartmentRepository.java
├── DepartmentService.java
├── DepartmentController.java
└── DepartmentDto.java      (record)
📦 DTO 使用 record

所有 DTO 转为 Java record，不可变、自带 equals/hashCode/toString。复杂 DTO 使用 Lombok @Builder：

@Builder
public record UserDto(
    Long id,
    @NotBlank String username,
    @Email String email,
    ...
) {}

Controller 参数加 @Valid 触发校验：

@PostMapping
public ResponseEntity<UserDto> create(@Valid @RequestBody UserDto dto)
🔐 关联集合用 Set 而非 List

所有 @OneToMany 和 @ManyToMany 使用 Set<Entity> + LinkedHashSet，避免 Hibernate Bag 语义下的重复和更新问题：

@OneToMany(mappedBy = "parent", cascade = CascadeType.ALL, orphanRemoval = true)
@OrderBy("sort ASC")
private Set<Department> children = new LinkedHashSet<>();
🧬 BaseEntity 抽象基类

公共的 id、createdAt、@PrePersist 提取到 @MappedSuperclass：

@Getter @Setter
@MappedSuperclass
public abstract class BaseEntity {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    @Column(updatable = false)
    private LocalDateTime createdAt;
    @PrePersist
    protected void onCreate() { createdAt = LocalDateTime.now(); }
}

🔄 双向关联同步

创建 User 时同步维护 Department.users 集合，保持双方一致性：

if (dto.getDepartmentId() != null) {
    Department dept = deptRepo.findById(dto.getDepartmentId()).orElse(null);
    u.setDepartment(dept);
    if (dept != null) dept.getUsers().add(u);  // 同步反向
}
